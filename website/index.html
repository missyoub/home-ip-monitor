工作原理

路由器通过 cron 定时执行脚本：先从公网 IP 服务获取本机出口 IP，再通过 GitHub API 把 IP 写入一个私有 Gist；本页面（GitHub Pages 静态托管）读取该 Gist 并展示。全程无需自建服务器。

命令行查询说明

GitHub Pages 是纯静态托管，无法在页面路径上动态返回数据，因此命令行查询直接读取同一个 Gist 的纯文本文件（与页面数据同源、实时一致）：
curl -s https://gist.githubusercontent.com/missyoub/b9eef32f878cf1829591bc338bf2a26c/raw/ip.txt
Windows PowerShell：iwr https://gist.githubusercontent.com/missyoub/b9eef32f878cf1829591bc338bf2a26c/raw/ip.txt
可设置别名方便日常使用，例如在 .bashrc 中加 alias homeip="curl -s https://gist.githubusercontent.com/missyoub/b9eef32f878cf1829591bc338bf2a26c/raw/ip.txt"。

路由器脚本（OpenWrt / 梅林等支持 cron + curl 的固件）

见仓库 router/report-ip.sh（推荐，含历史记录，需 jq）或 router/report-ip-simple.sh（无依赖精简版）

配置 crontab（每 10 分钟上报一次）

*/10 * * * * /root/report-ip.sh >/dev/null 2>&1

注意事项

1. 路由器脚本中的 GitHub Token 建议使用仅勾选 gist 权限的独立 classic token，不要使用部署仓库用的 token。
2. Gist 为秘密可见（secret），仅凭 ID 可访问；如担心 IP 泄露，请勿向他人透露本页地址。
3. Gist raw 内容有约 5 分钟 CDN 缓存，页面显示的「最后上报时间」以数据本身为准。
4. 判定规则：超过 30 分钟无上报会显示「未按时上报」警告（对应每 10 分钟一次的上报频率）。
